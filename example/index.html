🔒 What about third-party provider keys?
Provider credentials (such as Google Gemini and Groq) are never stored in this browser app. They are stored securely in your project's AES-256-GCM encrypted vault via the OneAPI Dashboard > API Providers tab. The OneAPI gateway handles failover, rate limiting, and decryption on the server.
